`30_articles/2026-W31/` に3本の下書きがあります。

| ファイル | 投稿 | 種別 |

**各ファイルの先頭にHTMLコメントで `[要確認]` が入っています。**
これは私（AI）が確認できなかった部分です。**投稿前に必ず直してください。**
特に「プログラミング未経験」という表現は、あなたの実際のレベルに合わせて書き換えが必要です。

有料記事は `━━━ ここから有料 ━━━` の行が境界です。
note編集画面で、その位置に有料エリアの区切りを入れてください。

## 毎週のサイクル

| 曜日 | やること |
|---|---|
| 月 | 無料①を投稿 |
| 木 | 無料②を投稿 |
| 土 | 有料を投稿 |
| **日** | **実際に何か作る・試す** → `00_strategy/INTAKE.md` の「今週やったこと」に3行書く |

**日曜が生命線です。** ここが止まると、書くべき一次情報が枯れ、
記事が「AIが書いた一般論」に落ちて売れなくなります
（noteのアルゴリズムは1次情報を優先するため、露出でも負けます）。

## この仕組みの制約（正直に）

| | |
|---|---|
| note.com へのアクセス | ❌ このセッションの通信ポリシーでブロック済み。**あなたのアカウントは未確認です** |
| note へのログイン・自動投稿 | ❌ 不可。投稿は手動コピペが必要です |
| PV・売上などの非公開数値 | ❌ 取得不可。`INTAKE.md` に貼ってください |
| 市場データの調査 | ✅ Web検索経由で可能（実施済み・`MARKET-ANALYSIS.md`） |
| 記事の企画・執筆 | ✅ 可能 |
| 定期実行 | ✅ Routineで毎週自動生成 |

**したがって、この仕組みが機能するかどうかは `INTAKE.md` が埋まるかにかかっています。**
そこが空のまま回すと、私は一般論しか書けません。そして一般論は売れません。
