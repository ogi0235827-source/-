# 情報リクエスト ― 分析精度を上げるために必要なもの

最終更新: 2026-08-01

## なぜこのファイルがあるか

このセッションからは **note.com にアクセスできません**（外部通信ポリシーによるブロック。
`prtimes.jp` など他のいくつかのドメインも同様）。Web検索での市場データ取得はできましたが、
**あなたのアカウントそのものは一度も見られていません。**

また、note のダッシュボード（PV・購入数・売上・読了率）は
ログインが必要な非公開データなので、仮にアクセスできても取得できません。

したがって以下は **あなたが貼ってくださる必要があります。**
貼っていただければ、戦略・記事テーマ・値付けを実データで上書きします。

---

## A. アカウントの現状（初回だけ・最優先）

```
プロフィール文（コピペ）:

フォロワー数:
投稿記事数:
うち有料記事:
アカウント開設時期:

既存記事のタイトル一覧（あれば全部）:
1.
2.
3.

最もスキが多かった記事とスキ数:
```

## B. 数値（毎月1回でOK）

| 項目 | 値 |
|---|---|
| 月間PV | |
| フォロワー増減 | |
| 有料記事の販売部数（記事別） | |
| 売上 | |
| 最も読まれた記事 | |
| 最も読まれなかった記事 | |

> 記事別の「読まれた数 vs 売れた数」が分かると、
> **「タイトルが悪いのか / 中身が悪いのか」を切り分けられます。** ここが一番効きます。

## C. 今週やったこと（毎週・記事の原料）

これが **一次情報の供給源** です。ここが空だと記事が一般論に落ちます。
箇条書きで構いません。うまくいかなかったことほど価値があります。

```
今週作ったもの / 試したこと:
-

うまくいかなかったこと・詰まったこと:
-

意外だったこと・発見:
-

使ったツール / モデル / プロンプトで効いたもの:
-
```

## D. 書きたくないこと・NGライン

```
触れたくない話題:
明かしたくない個人情報（勤務先・居住地・家族の写り込みなど）:
使いたくない表現・トーン:
```

> 特に「子供向けゲーム」を題材にする記事では、
> **お子さんの個人情報・写真・年齢の特定につながる記述** をどこまで出すか、
> 事前に線を引いてください。デフォルトでは一切書きません。
