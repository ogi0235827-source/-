# 売れているnoteの分析 ― なぜ売れるのか

最終更新: 2026-08-01

このドキュメントは「売れているnoteアカウントが、なぜ売れているのか」を、
一次ソース（note社の公式発表・note編集部の分析）を優先して整理したものです。

> **調査上の制約（先に明記）**
> このセッションの外部通信ポリシーにより `note.com` / `prtimes.jp` などへの
> 直接アクセス（ページ取得）はブロックされています。したがって
> **個別アカウントのページを開いて中身を読む形の分析はできていません。**
> 以下は Web検索で取得できた公開情報（note社の発表値・note編集部の分析結果）と、
> そこから導いた解釈です。数値は出典付き、解釈は「解釈」と明記しています。

---

## 1. 市場のかたち（note社の公式データ）

note社が **約30万件の有料記事**（2024年12月〜2025年11月に販売されたもの）を分析した結果:

| 指標 | 数値 |
|---|---|
| メンバーシップ売上 | 前年比 **+81.3%** |
| メンバーシップ購入数 | 前年比 **+86.3%** |
| 有料記事売上 | 前年比 **+26.8%** |
| 有料記事で収益を得たクリエイター数 | 前年比 **+42.0%** |
| 売上上位1000クリエイターの平均年間売上 | 約 **1,515万円** |

出典: [note株式会社プレスリリース](https://prtimes.jp/main/html/rd/p/000000360.000017890.html) / [note公式](https://note.jp/n/n8522197d1ced)

**読み取れること（解釈）**
- 売上の伸び（+26.8%）より **クリエイター数の伸び（+42.0%）が大きい**。
  つまり **参入者が増えて1人あたりの取り分は薄まっている**。「出せば売れる」局面は終わっている。
- 一方でメンバーシップは +81.3% と突出。**単発販売より継続課金のほうが伸びている**。
  → 単発の有料記事だけで設計せず、**最初から「積み上がる構造」で書く**べき。

---

## 2. 売れるテーマ ― 伸びているのは2系統

note社の分析では、伸びているカテゴリは大きく2つに分かれる。

**① 収入・キャリアが上がる系**
- テクノロジー / AI活用
- SNS運用
- 副業・リモートワーク

**② 日常の課題を解決する系**
- 子育て・教育

出典: [note株式会社](https://note.jp/n/n8522197d1ced)

**あなたの選択（AI・生成AI活用 / 副業・マネタイズ）は①のど真ん中。**
市場選択としては正しい。ただし後述のとおり **最も供給過多で、最も「AIで書いた薄い記事」が溜まっている領域** でもある。

---

## 3. 価格 ― 「実用ノウハウ系」は「読み物系」の約1.9倍で売れている

売れ筋上位20%の有料記事を分類して平均価格を出した結果:

| 記事タイプ | 上位20%の平均価格 |
|---|---|
| 実用ノウハウ系（手順・型・再現性がある） | **1,842円** |
| 読み物系（エッセイ・体験談として読ませる） | **983円** |

出典: [note株式会社](https://note.jp/n/n8522197d1ced)

**読み取れること（解釈）**
- 同じ体験を書いても、**「読み物」として出すか「手順」として出すかで価格が約1.9倍変わる**。
- これは文章力の差ではなく **パッケージングの差**。
  「私はこうしました」で終わらせず「あなたがこうすれば再現できます」まで書くかどうか。
- ただし **いきなり1,842円は初心者の取れる価格ではない**。これは既に売れている上位20%の実績値。
  → 値付けは §7 の段階設計を参照。

## 4. 売れるタイトルの3条件

note編集部が **有料記事500件** を分析した結果、購入されやすいタイトルの共通点:

1. **具体性**（数字・固有名詞・期間が入っている）
2. **読者にとってのベネフィットが明確**（読むと何が手に入るか）
3. **時流性**（今この瞬間に価値がある話題か）

出典: [note編集部「有料記事500件を分析して見えた、noteで購入されやすいタイトル設計の基本」](https://note.com/notemag/n/n367ec637ae54)

→ 実際のチェックリストは `note/20_templates/title-checklist.md` に落としてあります。

## 5. 最重要 ― noteのアルゴリズムは「1次情報」を優先する

note CXO・深津貴之氏の解説として繰り返し引用されている原則:

> noteが優先しておすすめするのは **「1次情報」や「生の体験の記録」**。
> AIはあなたの経験を作るものではなく、あなたの中にある出来事や感情を
> 整理して伝わる文章に変えるためのツール。

出典: [SBクリエイティブ ビジネス+IT](https://www.sbbit.jp/article/cont1/182197) ほか

あわせて重要な事実:
- **noteにはフォロワー数に依存しないおすすめアルゴリズムがある。**
  質の指標が高い記事は、フォロワーが少なくてもおすすめ欄・カテゴリページに出る。
  出典: [ひで｜AI時短ツール](https://note.com/tothinks/n/nd467f2eef0d7)

**これが「なぜ売れているか」の核心（解釈）**

売れているアカウントに共通しているのは、文章力でもSEOでもなく
**「その人しか書けない一次情報を持っていること」**。

逆に言うと、いま最も売れないのは
**「AIに書かせたAI活用ノウハウ」**。読者は既にそれを大量に見ていて、見分けがつく。
そして note のアルゴリズム自身が1次情報を優先するので、露出でも負ける。

> あなたが選んだ「AI活用 × 副業」は、**この罠が最も深いジャンル**です。
> 対策は `ACCOUNT-STRATEGY.md` に書きました。

## 6. 売れている人がやっている導線設計

| 仕掛け | 効果 | 出典 |
|---|---|---|
| **無料記事を先に積む** | 文章力・知識量を読者が判断できる → 有料購入のハードルが下がる | [sungrove](https://www.sungrove.co.jp/note-paid-article/) |
| **マガジンにまとめる** | 読者の回遊が生まれ、複数記事の購入につながる | 同上 |
| **外部からの流入**（X / ブログ / YouTube） | 母数を増やす。noteだけに閉じない | 同上 |
| **メンバーシップ** | 前年比+81.3%。単発より伸びている | note社 |

**構造として（解釈）**

```
無料記事（信頼の証明・実力の開示）
        ↓
有料記事（再現手順・具体物）
        ↓
マガジン / メンバーシップ（積み上げ・継続課金）
```

無料記事は「集客用の薄い記事」ではなく **「この人は本物だ」と証明する場所**。
ここをケチると有料が売れない。無料で出し惜しみしないほうが結果的に売れる。

## 7. 値付けの段階設計（このアカウント向けの推奨）

上位20%の平均が1,842円だからといって、実績ゼロで1,842円は売れません。
販売実績と「購入者の声」が価格の裏付けになるため、段階的に上げます。

| 段階 | 条件 | 価格 | ねらい |
|---|---|---|---|
| Phase 1 | 販売実績ゼロ | **500円** | まず「売れた」という事実を作る。心理的ハードル最小 |
| Phase 2 | 累計10部 or 好意的な反応が付いた | **980円** | 読み物系の相場。ここが基準線 |
| Phase 3 | 内容を体系化・テンプレ/コード等の具体物を同梱 | **1,480〜1,800円** | 実用ノウハウ系の相場（1,842円）に接近 |
| Phase 4 | 記事が5〜10本溜まった | メンバーシップ **月500〜980円** | 伸び率+81.3%の本命に乗る |

**値上げのルール**: 値上げ前に必ず「値上げ予告」を無料記事で出す。
予告そのものが購入動機になり、旧価格での駆け込み購入が発生します。

## 8. この分析から導いた「やらないこと」

| やらない | 理由 |
|---|---|
| AIに丸投げして書いた汎用ノウハウ記事 | 1次情報優先のアルゴリズムで露出しない／読者に見抜かれる |
| 「月◯万円稼げました」系の実績アピール（実績がないうちは） | 嘘になる。noteは信頼が資産のプラットフォーム |
| 毎日投稿で本数を稼ぐ | 質の指標が下がる。週3で1次情報を確保するほうが強い |
| いきなり1,800円 | 実績ゼロでは売れず、「売れない」データだけが残る |
