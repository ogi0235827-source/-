# 週次記事生成の指示書

このファイルは、定期実行（Routine）が毎週読む作業指示です。
手動で回したいときは、Claude にこのファイルを読ませてください。

---

## 作業手順

### 1. 現状を読む

以下を順に読む。

- `note/00_strategy/ACCOUNT-STRATEGY.md` — 方針
- `note/00_strategy/MARKET-ANALYSIS.md` — 売れる根拠
- `note/00_strategy/INTAKE.md` — **★最重要。ユーザーが埋めた一次情報**
- `note/10_calendar/EDITORIAL-CALENDAR.md` — 今週のテーマ
- `note/30_articles/` の直近週 — 既出の内容と重複させない

### 2. INTAKE.md の「今週やったこと」を確認する

**ここが埋まっているかどうかで、やることが変わる。**

| 状態 | 対応 |
|---|---|
| 埋まっている | その内容を一次情報の核として3本書く |
| **空**、または前週から更新なし | **一般論で埋めない。** §5 に従う |

### 3. 記事を3本書く

`note/30_articles/<年>-W<週番号>/` に作成。

| ファイル | 型 | テンプレ |
|---|---|---|
| `free-01-*.md` | 体験記録（月） | `20_templates/free-article.md` 型A |
| `free-02-*.md` | 小さな実用（木） | `20_templates/free-article.md` 型B |
| `paid-01-*.md` | 実用ノウハウ（土） | `20_templates/paid-article.md` |

**必ず守る**

- 各ファイル冒頭に、HTMLコメントで `[要確認]` 事項を列挙する
  （AI側が確認できていない・想像で書いた箇所を必ず明示する）
- 有料記事には `━━━ ここから有料 ━━━` の境界行を入れる。無料部分は全体の約30%
- **結論は無料部分に出し切る。** 有料で売るのは手順・判断基準・コピペできる具体物
- タイトルは `20_templates/title-checklist.md` の3条件（具体性・ベネフィット・時流性）を全部満たす
- 有料記事は**実用ノウハウ系**として書く（読み物系の約1.9倍の単価帯）
- 価格は `ACCOUNT-STRATEGY.md` の現在のPhaseに従う（現在: **Phase 1 = 500円**）

### 4. 絶対にやってはいけないこと

- **実績・数値の捏造。** 「月◯万円稼げました」を実績なしに書かない。
  noteは信頼が資産のプラットフォームで、一度失うと回復できない
- **一次情報がないのに体験記録の形にすること。** それは嘘になる
- **お子さん・家族・勤務先・居住地が特定できる記述。** デフォルトで一切書かない
- **note.com へのアクセス試行。** このセッションの通信ポリシーでブロックされている。
  代わりに WebSearch を使う（WebFetch は全ドメインで 403 になる）

### 5. INTAKE.md が空だったときの対応

**一般論で3本を埋めない。** 代わりに:

1. リポジトリの `git log` / 差分から、まだ記事にしていない一次情報を探す
2. 見つかれば、それを核に書く
3. **見つからなければ、記事は無料1本のみに減らし**、
   残り2本は「ネタが枯れているので INTAKE.md の記入が必要」と報告する

**本数を守るために中身のない有料記事を出すのが、最も回復しにくいダメージ。**
本数より一次情報を優先する。

### 6. 市場の再調査（月1回・月初のみ）

WebSearch で以下を確認し、変化があれば `MARKET-ANALYSIS.md` を更新する。

- note社の新しい公式データ発表
- 伸びているジャンルの変化
- 価格帯の変化

出典URLを必ず併記し、**数値は出典付き / 解釈は「解釈」と明記**する。

### 7. コミットして報告する

```
git add note/
git commit -m "note: <年>-W<週番号> の記事3本を追加"
git push -u origin claude/note-account-analysis-8bkt2y
```

報告に含めるもの:

- 書いた3本のタイトル
- 各記事で `[要確認]` にした箇所（＝ユーザーの確認が必要な点）
- INTAKE.md が空だった場合はその旨と、本数を減らした事実
- 次週に向けて必要な一次情報のリクエスト
