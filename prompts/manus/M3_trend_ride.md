# M3: トレンドトピックに乗ったコンテンツを作る

> **起動条件**: X/SNS全体でAI関連のトレンドトピックが発生している  
> **所要時間（Manus）**: 10〜15分  
> **出力**: トレンドに乗った投稿3〜5本（速報性重視）

---

## ▼Manusに貼るプロンプト▼

## タスク概要

SNS分析でトレンドトピックが発生していることを確認しました。
**速報性が命**なので、今すぐ私のアカウントが乗れるコンテンツを作成してください。

## 私のアカウント情報

- **ジャンル**: AIツール紹介・アフィリエイト（X/Threads）× AI画像生成（Instagram）
- **ターゲット読者**: 日本語話者、AI初心者〜中級者、副業・マネタイズに興味あり
- **ポジション**: 「AI初心者でも使える情報を日本語でわかりやすく」

## 今日のトレンド情報

【ここに分析結果のトレンド情報を記入】
- トレンドのキーワード/ハッシュタグ: 
- トレンドの概要（何が起きているか）: 
- 競合はどう扱っているか: 
- 私のジャンルとの関連性: 

## 実行手順

1. 指定されたトレンドキーワードについて最新情報を検索する（英語・日本語両方）
2. 事実確認をする（誤情報に乗らないよう注意）
3. 私のジャンル（AI/副業）の視点からそのトレンドを解説する角度を考える
4. 速報性を重視した投稿を作成する

## 出力形式

### 事実確認サマリー

```
【トレンドの事実】
- 何が起きているか（一言）: 
- 情報ソース: 
- 信頼度（高/中/低）: 
- 私のアカウントで扱って良い内容か（Yes/No）: 
```

### 投稿コンテンツ（速報重視）

**X投稿①: 速報ツイート**（フォロワーへの速い情報提供）
```
[投稿文 - 140字以内]
```

**X投稿②: 解説ツイート**（初心者向けわかりやすい解説）
```
[投稿文 - 140字以内]
```

**X スレッド: 深掘り解説**（3〜5ツイート）
```
1/ [強いフック]
2/ [背景・経緯]
3/ [具体的な影響・メリット/デメリット]
4/ [私のジャンルへの関連性]
5/ [まとめ・CTA]
```

**Threads投稿**（Xより少し長め・会話型）
```
[Threads向け投稿文]
```

**Instagram キャプション**（トレンドに乗りつつAI画像と組み合わせ）
```
[IG向けキャプション + ハッシュタグ]
```

### 投稿タイミング提案

トレンドが最も拡散されやすいタイミングに合わせた投稿順序と時間を提案してください。

### 注意事項

以下の点があれば必ず警告してください：
- 情報が不確かな場合
- センシティブなトピックの場合
- 誤解を招きやすい表現がある場合

## 成功基準

- 全投稿が5分以内に実際に投稿できる状態になっている
- 事実に基づいている
- 私のアカウントのポジションと一貫している
