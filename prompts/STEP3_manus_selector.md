# STEP3: Manusプロンプト選択ガイド

> STEP2の分析結果を見て、このガイドで「どのManusプロンプトを使うか」を決める

---

## Manusに渡す前の準備（2分）

STEP2の「【分析6】Manus起動判定」で✅がついた項目のプロンプトを開き、
以下の`【ここに...を記入】`の部分に分析結果を貼り付けてから Manus に渡す。

---

## プロンプト選択フローチャート

```
STEP2の分析結果を見る
         │
         ├─ 競合がやってるのに自分がやっていないトピックがある
         │         └─→ M1_content_gap.md を使う
         │
         ├─ 競合の特定フォーマットが自分より明らかに高エンゲージメント
         │         └─→ M2_viral_clone.md を使う
         │
         ├─ SNS全体でAI関連トレンドが発生している
         │         └─→ M3_trend_ride.md を使う（速報優先）
         │
         ├─ 自分のエンゲージメント率が競合の50%以下
         │         └─→ M4_engagement_fix.md を使う
         │
         ├─ 自分の投稿数が競合の半分以下
         │         └─→ M5_schedule_optimize.md を使う
         │
         ├─ 今日が月曜日
         │         └─→ M6_weekly_calendar.md を使う（毎週月曜）
         │
         └─ 今日が月末（25日以降）
                   └─→ M7_account_audit.md を使う（月1回）
```

**複数該当する場合**: 上のものほど優先度が高い。ただしM3（トレンド）は最速対応が命なので、
他と被った場合はM3を先に実行してから他のプロンプトを使う。

---

## Manusへの渡し方（3ステップ）

### Step A: 該当プロンプトファイルを開く
`prompts/manus/M[番号]_[名前].md` を開く

### Step B: カスタマイズ箇所を埋める
プロンプト内の `【ここに...を記入】` の部分に STEP2 の分析結果を貼る

### Step C: Manusに貼って実行
プロンプト全文（「## タスク概要」から「## ▲ここまで▲」まで）をコピーして Manus のチャット欄に貼る

---

## Manusの出力を受け取った後

| Manusから出力されるもの | 次にやること |
|---|---|
| 投稿下書き（M1/M2/M3/M4） | そのままコピーしてSNSに投稿 |
| 週間カレンダー（M6） | 予約投稿ツール（Publer等）に入力 |
| スケジュール表（M5） | カレンダーアプリに転記 |
| 月次レポート（M7） | 翌月の分析テンプレに保存 |

---

## よくある状況別の推奨プロンプト

| 状況 | 推奨 |
|---|---|
| 「今日何を投稿すればいいかわからない」 | M6（月曜）→ カレンダーを先に作る |
| 「競合がバズっていて焦っている」 | M2 → バズフォーマットを即真似る |
| 「いいねが全然もらえない」 | M4 → エンゲージメント回復投稿を作る |
| 「投稿ネタが尽きた」 | M1 → 競合のギャップを埋めるネタを作る |
| 「ChatGPT新機能発表があった」 | M3 → 速報コンテンツを最速で作る |
| 「月初で方向性を決めたい」 | M7（前月末実行）→ 翌月戦略を作る |
